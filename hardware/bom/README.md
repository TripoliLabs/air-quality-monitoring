| Component | Part | Cost (USD) |
|-----------|------|------------|
| Gateway | Dragino DLOS8N (EU868, 4G backhaul) | ~$200 |

## Deployment Estimates

- **Pilot (10 nodes + 1 gateway):** ~$700-830
- **Neighborhood (50 nodes + 2 gateways):** ~$3,100-3,600
- **City-scale (200 nodes + 5 gateways):** ~$12,000-14,000
